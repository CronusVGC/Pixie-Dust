Cryptographic Transparency & Specifications

How Pixie Dust Operates

Pixie Dust implements a client-side visual obscuration and access-gating pipeline designed to scramble image pixels before transmission across untrusted networks.

COMPONENT 01 PBKDF2-HMAC-SHA256

100,000 Rounds Key Derivation

Standard WebCrypto PBKDF2 iterates 100,000 times over SHA-256 with a unique 16-byte cryptographically secure random salt (`crypto.getRandomValues`) to derive a 256-bit PRNG seed and a 32-bit verifier tag. This increases resistance against dictionary and brute-force attacks.

COMPONENT 02 Fisher-Yates Permutation

Spatial Pixel Permutation

Using the deterministic Xoshiro128** PRNG seeded by the master key, pixel coordinates are shuffled across the entire image dimensions. This completely disrupts spatial correlation, object edges, and geometric layout.

COMPONENT 03 Keystream XOR Mask

RGB Keystream Diffusion

Each shuffled pixel's Red, Green, and Blue color channels are bitwise XOR-masked with pseudo-random bytes generated from the PRNG stream. This flattens the image histogram and prevents color frequency profiling.

COMPONENT 04 LSB Steganography

100% Lossless Header Embedding

Channels 0..159 store the 16-byte salt and 4-byte verifier tag. To eliminate pixel corruption, channels 160..319 back up the original LSBs of channels 0..159. Decryption restores these exact bits, achieving 100% loss-free pixel reconstruction.

HONEST SCOPE & CRYPTOGRAPHIC CLARITY

Pixie Dust is a client-side visual scrambling and access-gating tool. It is designed to disguise photos into static visual noise before leaving the device and prevent unauthorized viewing without the passphrase. It is distinct from authenticated block ciphers (such as AES-GCM) and requires lossless file formats (like PNG) to preserve steganographic header bits.
