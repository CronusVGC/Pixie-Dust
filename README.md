# 🧚 Pixie-Dust

## Secure Image-Based Data Protection

Pixie-Dust is a web-based security project that combines password-based key derivation, image processing, pixel permutation, and data transformation to protect sensitive information using images.

## 🚀 Features

- 🔐 Password-based key derivation
- 🖼️ Image-based data protection
- 🔀 Pixel permutation
- 🧩 Cryptographic processing pipeline
- 📦 File processing utilities
- 💪 Password strength checking
- 🌐 Web-based interface
- 🧪 Demo payload for testing

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- Python
- Streamlit
- SHA-256 / HMAC
- PBKDF2
- Image processing
